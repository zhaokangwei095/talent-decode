# 选题与方向：原站抓取 vs 本次重设计

抓取时间：2026-10-15
来源：`https://talent.easydj.cloud/`（单页测评，题目与报告均由接口下发）
原始数据：`data-source/raw_questions.json`、`data-source/raw_report.json`

---

## 一、原站结构（抓取结果）

| 项 | 原站做法 |
|---|---|
| 题量 | 50 题，全部同一套 5 级频率量表 |
| 维度 | 10 项（加德纳多元智能 + 创造/美学扩展） |
| 出题方式 | `GET /question/{i}` 逐题下发，前端预取下一题 |
| 计分 | `POST /submit` 提交后由服务端返回整段 HTML 报告 |
| 报告 | 雷达图 + 排序条 + 类型解读 + 2 项详解 + 职业推荐 + 避坑 + 7 天计划 |
| 进度 | localStorage + `/save-progress` 双保险 |
| 视觉 | 紫色渐变 + 圆角卡片 + emoji 图标 + 大量阴影 |

原站 10 个维度与题量分布（每维 5 题）：

```
语言表达 逻辑分析 空间想象 自我觉察 人际理解
身体操作 音乐感知 自然观察 创新创造 审美设计
```

---

## 二、原站的四个结构性问题

**1. 50 题全是同一种问法。**
每题都是"我很擅长 X"式的自评。同一种量表重复 50 次，测的是"你怎么评价自己"，而不是"你怎么做事"。自我评价最容易受期待和情绪影响。

**2. 能力和兴趣混在一个分里。**
原站靠兴趣（霍兰德）推导职业，但题目里没有任何一题问"你愿不愿意做"。于是"会做"和"想做"被合并成一个数，推荐结果经常出现"能力匹配但完全不想干"的方向。

**3. 类型归类过于依赖三个示例。**
首页只展示 3 个类型（沟通创意型/逻辑创新型/艺术表现型），但 10 个维度两两组合的可能远不止 3 种，实际落不到展示的类型上时，报告会给出未在首页出现的类型，用户会困惑。

**4. 报告只讲优点，不讲代价。**
"你的优势"写得很足，但"这份工作真实的一面""你现在进去会吃力在哪"几乎是空白。这类报告读完让人高兴，但帮不上决策。

---

## 三、本次重设计的三层提问

核心改动：**把"你觉得自己怎样"换成"你实际怎么做 + 你愿意做什么"**。

| 部分 | 题量 | 问法 | 测什么 |
|---|---|---|---|
| A 行为表现 | 36 | 具体行为发生的频率（1-5） | 能力倾向 |
| B 工作模式 | 8 | 两个方向强制二选一 + 程度 | 偏好轴 |
| C 兴趣倾向 | 18 | 想不想做（与能力无关） | 兴趣 |
| 合计 | 62 | | |

### A 部分：12 维度 × 3 题

维度沿用原站 10 项（保留可比性），补充 **学习适应**、**执行统筹** 两项——这两项在职业适配里的解释力很强，原站缺失导致"适应变化快""交付靠谱"这两类人无处安放。

题干全部改写为可观察的行为。对照示例：

| 原站 | 重设计 |
|---|---|
| 我能够准确描述复杂的想法，让别人容易理解。 | 需要把一件复杂的事讲清楚时，你能很快找到一个贴切的比喻或例子。 |
| 别人经常说我善于发现问题中的关键点。 | 别人给出一个结论，你会先去确认它的前提和推理链条站不站得住。 |

区别在于：后者描述的是一个**能被回忆的具体场景**，而不是一个**需要自评的结论**。

### B 部分：4 条偏好轴

原站完全没有这一层。强制取舍比自评更难伪装，因为它不给你"我都行"的出口。

```
秩序 ⟷ 探索    需要多确定的环境才能安心发力
对人 ⟷ 对事    能量主要流向人，还是东西与信息
专深 ⟷ 广博    适合扎一口深井，还是铺一张网
构想 ⟷ 落地    擅长把事想出来，还是把事做扎实
```

这 4 轴直接解释"为什么同样的能力，在两个环境里表现差很多"，也是报告里工作模式建议的依据。

### C 部分：6 个兴趣族

沿用霍兰德 RIASEC 六角模型（原站只在报告里用了结论，没有对应题目），但题干全部换成 2026 年可被真实体验到的活动：

```
R 动手实作   I 钻研探究   A 创意表达
S 助人联结   E 影响推动   C 秩序经营
```

## 四、职业池的改动

原站职业推荐存在两类问题：只写"为什么适合"，不写"坑在哪"；以及推荐与避坑会互相矛盾。

重设计后每个职业都带四个字段：

```
need   岗位对各项能力的真实要求（0-25，与测评同一把尺）
fit    一句话说清这份工作到底在做什么
risk   这份工作真实的一面（不美化）
start  现在就能做的第一步
```

匹配算法：`契合度 = Σ min(你的分数, 岗位要求) / Σ 岗位要求 × 100%`，兴趣同向再加 6 分。用 `min()` 是为了避免"某项超强就拉高整体"，超出的部分对这份工作没有额外价值。

避坑清单有两个硬约束，修掉了原站的矛盾：

1. 不能出现在推荐列表里；
2. 该短板本身必须确实不突出（低于 60 分），否则不写"偏低"。

并且每条都给出具体数值对照（如"这项需要 23/25，你目前 6.3/25"），而不是笼统说"需要逻辑能力"。

## 五、类型体系

原站 3 个示例类型 → 重设计 10 个类型（4 个集群两两组合，含同集群加强型）。

4 个集群把 12 个维度归成可解读的大方向：

```
表达联结（语言/自我觉察/人际理解）   —— 把东西传递出去
构想创造（空间想象/创新创造/审美设计）—— 生成新的形式与可能
分析建构（逻辑分析/学习适应/执行统筹）—— 搭起结构与路径
体验感知（身体操作/音乐感知/自然观察）—— 直接捕捉世界的信息
```

取分最高的两个集群组成类型（如"表达联结 + 构想创造 = 表达创造者"）。两个集群分差小于 6 分时标记为"并列型"，并明确提示不要只记类型名。

## 六、报告的信息层级

原站报告是平铺的卡片流。重设计改为编号档案式结构，共 10 节：

```
§01 类型解读        为什么是这类 + 底牌 + 要留神的地方
§02 天赋分布图      雷达图（固定轴序）+ 四大方向条形
§03 十二项排序      完整分数与档位
§04 优势详解        前 4 项：常见表现 / 会踩的坑 / 适用场景 / 马上能试的做法
§05 暂时不突出的三项 给"怎么绕过"，不给"怎么补短板"
§06 工作模式        4 条偏好轴的解读
§07 你愿意做的事     兴趣六族
§08 匹配的方向       6 个方向，每个带真实代价与第一步
§09 建议谨慎的方向   带数值对照的缺口说明
§10 7 天验证计划     按本人的第一名与首选方向定制
```

两个刻意的设计选择：

- **雷达图用固定轴序**（按集群排列）。若按得分排序，每个人的图形都是"前大后小"，图形本身就不携带信息了。
- **弱项章节写"怎么绕过"而不是"怎么提升"**。在弱项上投入的回报通常远低于把强项再拉高一档，报告应该诚实说这件事。

---

## 七、一致性校验

原站没有作答质量校验。重设计加了一条：统计 A 部分答案的**不同选项数**。若集中在 ≤2 个选项，报告末尾会提示"分数差距被压缩，排序参考价值下降，建议隔天放慢速度重测"。

这不能识别刻意作假的作答，但能拦住"一路点到底"的情况——而这是真实用户里最常见的一种无效数据。
